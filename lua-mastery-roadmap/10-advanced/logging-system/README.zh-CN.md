# 日志系统

**阶段**: 10 — 高级 | **难度**: 高级

## 描述

一个结构化日志系统，支持多级日志级别和可配置的格式化器，并可同时输出到控制台和文件。讲解 Lua 模块设计与 I/O 模式。

## 前置知识

- Lua 5.1+ 或 LuaJIT
- 理解 Lua 模块与元表

## 运行方法

```bash
lua 01-logging-system.lua
```

## 核心概念

- 日志级别层次（DEBUG < INFO < WARN < ERROR）
- 格式化器插件与输出策略
- 基于元表的模块设计
- 文件与控制台输出

## 文件

- `01-logging-system.lua` — 支持日志级别、格式化器以及文件/控制台输出的日志器
