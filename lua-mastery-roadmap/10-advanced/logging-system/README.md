# Logging System

**Stage**: 10 — Advanced | **Difficulty**: Advanced

## Description

A structured logging system with multiple log levels, configurable formatters, and output to both console and files. Teaches Lua module design and I/O patterns.

## Prerequisites

- Lua 5.1+ or LuaJIT
- Understanding of Lua modules and metatables

## How to Run

```bash
lua 01-logging-system.lua
```

## Key Concepts

- Log level hierarchy (DEBUG < INFO < WARN < ERROR)
- Formatter plugins and output strategies
- Module design with metatables
- File and console output

## Files

- `01-logging-system.lua` — Logger with levels, formatters, and file/console output
