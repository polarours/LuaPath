# 缓存系统

**阶段**: 11 — 高级

## 描述
构建一个支持存活时间（TTL）的高性能 LRU 缓存。了解数据结构如何支撑实际系统，实现淘汰策略，并理解内存占用与查找性能之间的取舍。

## 前置知识
- 阶段 01–10 已完成
- 熟练使用表格、元表和闭包
- 理解链表概念

## 运行方法
```bash
lua 01-cache-system.lua
```

## 核心概念
- LRU（最近最少使用）淘汰
- 基于 TTL 的过期
- 用双向链表实现 O(1) 操作
- 用于清理钩子的淘汰回调
- 容量管理
