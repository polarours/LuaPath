# 状态机

**阶段**: 12 — 高级

## 描述
实现一个通用的有限状态机（FSM），包含守卫条件、进入/退出回调和状态转换动作。探索如何用元表建模状态对象，以及 FSM 如何让游戏 AI、UI 导航这类复杂控制流变得清晰。

## 前置知识

- 熟练掌握元表和闭包
- 熟悉回调模式

## 运行方法

