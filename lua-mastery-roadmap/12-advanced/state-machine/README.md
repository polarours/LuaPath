# State Machine

**Stage**: 12 — Advanced

## Description
Implement a generic finite state machine (FSM) with guard conditions, entry/exit callbacks, and transition actions. Explore how metatables model state objects and how FSMs bring clarity to complex control flows like game AI or UI navigation.

## Prerequisites
- Stages 01–11 completed
- Strong grasp of metatables and closures
- Familiarity with callback patterns

## How to Run
```bash
lua 01-state-machine.lua
```

## Key Concepts
- Finite state machines (FSM)
- Guard conditions for transitions
- Entry/exit lifecycle callbacks
- Transition actions
- State object encapsulation via metatables
