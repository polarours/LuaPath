# Code Generation
**Stage:** 26 — Advanced

## Description
Explore Lua metaprogramming through code generation, dynamic string manipulation, the load() function, and DSL (Domain-Specific Language) construction. Learn how to generate and execute Lua code at runtime.

## Prerequisites
- Stages 1–25 completed
- Understanding of Lua load() and string manipulation
- Familiarity with metatables and closures

## How to Run
```bash
lua 01-code-generation.lua
```

## Key Concepts
- Runtime code generation with string.format and load()
- DSL construction for declarative APIs
- Template-based code expansion
- Dynamic function creation and evaluation
- Code transformation and generation pipelines

## Files
- `01-code-generation.lua` — Lua code generator, DSL construction, and runtime code loading
