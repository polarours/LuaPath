# 模板引擎

**阶段**: 8 — 中级 | **难度**: 中级

## 描述

一个简单的模板引擎，支持变量插值、条件分支和循环。讲解 Lua 的模式匹配与字符串操作能力。

## 前置知识

- Lua 5.1+ 或 LuaJIT
- 理解 Lua 字符串模式

## 运行方法

```bash
lua 01-template-engine.lua
```

## 核心概念

- 使用 Lua 模式匹配解析模板语法
- 通过 `{{variable}}` 进行变量插值
- 条件块 `{%if%}...{%end%}`
- 循环块 `{%for%}...{%end%}`

## 文件

- `01-template-engine.lua` — 支持变量、条件分支和循环的模板引擎
