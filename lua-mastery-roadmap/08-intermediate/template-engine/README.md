# Template Engine

**Stage**: 8 — Intermediate | **Difficulty**: Intermediate

## Description

A simple template engine with variable interpolation, conditionals, and loops. Teaches Lua's pattern matching and string manipulation capabilities.

## Prerequisites

- Lua 5.1+ or LuaJIT
- Understanding of Lua string patterns

## How to Run

```bash
lua 01-template-engine.lua
```

## Key Concepts

- Template syntax parsing with Lua patterns
- Variable interpolation with `{{variable}}`
- Conditional blocks with `{%if%}...{%end%}`
- Loop blocks with `{%for%}...{%end%}`
