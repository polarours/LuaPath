# Stage 43: 工具链模式

**级别**: 高级  
**描述**: 将 Lua 集成到构建系统、CI/CD 流水线和工作流包管理中。学习将 Lua 用作构建脚本语言和自动化开发工作流工具。

## 前置知识

- Stage 05 — Metatables
- Stage 12 — Performance
- Stage 28 — Deployment Patterns
- Stage 38 — Testing Patterns

## 学习目标

- 使用 Lua 作为脚本语言设计构建任务
- 将 Lua 代码验证和测试集成到 CI 流水线中
- 为 Lua 模块构建轻量级包管理器
- 使用 Lua 脚本创建自动化的部署工作流

## 项目

1. [Lua 构建系统](43-toolchain/lua-build-system/) — 使用 Lua 元表和依赖图的基于任务的构建系统
2. [CI/CD 集成](43-toolchain/ci-cd-integration/) — GitHub Actions 的 Lua 验证钩子、报告生成和自动化测试
3. [Lua 包管理器](43-toolchain/lua-package-manager/) — Lua 依赖解析器和包加载器

## 预估时间
