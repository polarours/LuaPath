# 第 35 阶段：内存池

## 标题
内存池 — 面向性能的对象快速分配与复用

## 描述
内存池预先分配一组固定对象并循环复用它们，而不是不断创建新对象再交给垃圾回收器。这能显著降低性能敏感型 Lua 应用（如游戏引擎、网络服务器和实时系统）中的 GC 压力和分配开销。

本实现提供一个通用的池，容量可配置、支持自动扩容、统计跟踪，并为获取/释放操作提供生命周期钩子。

## 前置知识
- Lua 表和元表
- 闭包和作为值的函数
- `setmetatable` 和 `__index` 元方法
- 对垃圾回收的基本理解
- 性能分析的基本概念

## 运行方式
```bash
lua5.4 01-memory-pool.lua
```

## 核心概念
- **对象池**：复用对象，而不是每次都分配新对象
- **预分配**：提前创建对象，避免运行时分配停顿
- **池容量**：配置最小/最大容量和扩容策略
- **获取/释放**：从池中借用对象，用完后归还
- **重置语义**：释放时清理对象状态，保证安全复用
- **统计跟踪**：监控池利用率、命中率和扩容事件
- **生命周期钩子**：获取（初始化）和释放（清理）时执行自定义逻辑
- **通用池**：通过工厂函数池化任意类型的对象
