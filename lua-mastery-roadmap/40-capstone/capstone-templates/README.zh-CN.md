# 综合项目模板

每个学习阶段都有一套结构化的入门项目。每个模板都包含骨架源文件、测试桩和明确的需求，引导学习者从带引导的起步项目走向完整实现。

## 阶段

| 模板 | 阶段 | 重点 | 用时 |
|----------|-------|-------|------|
| [文本数据工具](text-data-tool/) | 初级（阶段 1–3） | 文件 I/O、字符串模式、表操作、基本错误处理 | 8–10 小时 |
| [响应式管道](reactive-pipeline/) | 中级（阶段 2–4） | 元表/面向对象、协程、模块设计、背压 | 12–16 小时 |
| [脚本运行时](script-runtime/) | 高级（阶段 4–5） | 沙箱、热重载、元编程、错误隔离、C API 概念 | 16–20 小时 |
| [服务管理器](service-manager/) | 生产级（阶段 5–40） | 生产模式、健康检查、重启策略、结构化日志、GC 意识 | 20–30 小时 |

## 使用方式

1. **选择阶段**：挑一个你准备好的阶段（先看各模板 README 中的前置知识）。
2. **复制模板目录**到你的工作位置：
   ```bash
   cp -r capstone-templates/text-data-tool my-first-tool/
   ```
3. **实现每个 `src/` 文件中的 TODO**。`tests/` 下的测试桩展示了预期行为。
4. **运行测试**：
   ```bash
   lua tests/test_*.lua
   ```
5. **运行示例**，查看完成后的项目演示。

## 包含内容

- **`README.md`** — 完整需求与架构概览
- **`src/*.lua`** — 骨架实现，每一步都带 `TODO` 标记
- **`tests/*.lua`** — 展示预期行为的测试桩（随实现逐步扩展）
- **`examples/`** — 项目完成后即可运行的演示代码
- **`config/`** *(如适用)* — 示例配置文件

每个模板都刻意保持不完整——那些 `TODO` 标记就是练习本身。
你来补全实现，测试负责验证方案是否正确。
