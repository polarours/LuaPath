# 第 34 阶段：中间件管道

## 标题
中间件管道 — 用可组合的处理器串联请求处理

## 描述
中间件管道模式把处理函数串联起来，每个函数处理请求的一部分，再把它交给下一个处理器。每个中间件都可以修改请求/响应、短路整条管道，或加入日志、认证、速率限制之类的横切关注点。这是 Express.js、Koa 以及众多 API 网关的骨架。

本实现提供一条可组合、可扩展的管道，带有 before/after 钩子、错误处理，以及中止链路的能力。

## 前置知识
- Lua 闭包和一等函数
- 闭包的串联与组合
- 用元表实现类对象结构
- 使用 `pcall`/`xpcall` 进行错误处理
- 对 HTTP 请求/响应概念的基本理解

## 运行方式
```bash
lua5.4 01-middleware-pipeline.lua
```

## 核心概念
- **中间件函数**：签名为 `function(req, res, next)`、用于处理请求的函数
- **串联**：每个中间件调用 `next()`，把控制权交给下一个处理器
- **短路**：中间件不调用 `next()` 即可跳过后续处理器
- **错误中间件**：捕获上游中间件所抛错误的特殊处理器
- **可组合性**：用简单、可复用的中间件函数搭出复杂管道
- **请求/响应上下文**：贯穿整条管道流动的共享状态
- **Before/after 钩子**：围绕核心处理器的前置和后置处理
