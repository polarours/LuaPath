# 第 30 阶段：Active Record 模式

## 标题
Active Record 模式 — Lua 的对象关系映射

## 描述
Active Record 模式把数据库行绑定到对象上，由对象自身负责持久化。每条记录都知道如何从存储中保存、查找和删除自己。该模式通过把数据和行为集中在同一个类中简化了数据访问。

在本实现中，我们用 Lua 表作为内存存储，在不引入外部依赖的前提下演示这一模式。

- Lua 元表和 `__index`/`__newindex`

- 理解 Lua 中的面向对象模式

## 核心概念
- **模型类**：定义模式（schema）、校验和持久化方法
- **find**：按 ID 从存储中检索记录
- **save**：在存储中插入或更新记录
- **delete**：从存储中移除记录
- **校验**：在持久化前确保数据完整性
- **回调**：挂接到生命周期事件（before_save、after_create）
- **脏字段跟踪**：检测哪些字段发生了变化
