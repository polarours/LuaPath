# 事件系统

**阶段**: 13 — 高级

## 描述
构建一个发布/订阅事件总线，支持优先级排序、一次性处理器、通配主题匹配和错误隔离。了解解耦系统如何通过事件通信，以及如何在回调链中隔离故障。

## 前置知识
- 阶段 01–12 已完成
- 理解闭包与错误处理（pcall）
- 熟悉可变参数函数

## 运行方法
```bash
lua 01-event-system.lua
```

## 核心概念
- 发布/订阅模式
- 基于优先级的处理器执行顺序
- 一次性处理器
- 通配主题匹配
- 用 pcall 做错误隔离
