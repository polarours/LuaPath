# 阶段 4：内部机制与原生集成

**阶段**: 4 | **时间**: 30–40 小时 | **章节**: 10–11
**Lua Versions**: 5.1, 5.3, 5.4, LuaJIT

## 概述

理解虚拟机，并把 Lua 嵌入宿主程序。本阶段连接 Lua 与 C——对游戏引擎、插件与系统工具都至关重要。

- 主题：Lua 虚拟机模型、内存分配、C API、userdata、栈纪律
- 陷阱重点：栈溢出、userdata 生命周期、GC 引用跟踪

## 项目

| 项目 | 描述 | 技能 |
|------|------|------|
| 在 C 中嵌入 Lua | 一个 C 宿主程序：注册原生函数、在 C 与 Lua 之间传递数据。 | 栈式 C API 与栈纪律；`userdata` 的生命周期；错误处理与栈回退 |
