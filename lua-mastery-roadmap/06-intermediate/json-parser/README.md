# JSON Parser

**Stage**: 6 — Intermediate | **Difficulty**: Intermediate

## Description

Build a recursive descent JSON parser from scratch. Teaches lexer/tokenizer design, grammar-driven parsing, and error handling with line/column info.

## Prerequisites

- Lua 5.1+ or LuaJIT
- Familiarity with Lua tables and string functions

## How to Run

```bash
lua 01-json-parser.lua
```

## Key Concepts

- Recursive descent parsing
- Lexer/tokenizer design
- Grammar-driven parsing

## Files

- `01-json-parser.lua` — Complete JSON parser with test suite
