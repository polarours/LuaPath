# Stage 42: Performance Patterns

**Level**: Advanced  
**Description**: Build high-performance Lua code by understanding memory layouts, cache behavior, and optimization patterns. Focus on writing code that minimizes cache misses, aligns data for efficient access, and leverages Lua's fast paths.

## Prerequisites

- Stage 12 — Performance
- Stage 27 — Memory Management
- All previous stages

## Learning Objectives

- Design data structures optimized for cache locality
- Understand Lua's internal memory layout and allocation patterns
- Apply structural optimization to hot paths in Lua code
- Measure and validate performance improvements

## Projects

1. [Cache-friendly Patterns](42-performance/cache-friendly/) — Array-of-Structs vs Struct-of-Arrays optimization
2. [SIMD-style Patterns](42-performance/simd-patterns/) — Vectorized operations on Lua tables
3. [Memory Alignment](42-performance/memory-alignment/) — Efficient layout and padding patterns

## Time Estimate

8–12 hours per project
