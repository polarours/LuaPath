# 第 33 阶段：无锁队列

## 标题
无锁队列 — 使用原子操作的并发数据结构

## 描述
无锁队列用原子操作（比较并交换、加载链接/条件存储）代替互斥锁，实现线程安全的入队和出队。本实现在单线程 Lua 中借助协程和协作式调度来模拟原子操作，无需真正的操作系统线程即可演示无锁算法的核心概念。

无锁数据结构是高性能并发系统的基石：它们扩展性更好，并且避免了基于锁的方案固有的死锁。

## 前置知识
- Lua 表和元表
- 闭包和作为值的函数
- 协程基础（`coroutine.create`、`resume`、`yield`）
- 理解链表
- 基本并发概念

## 运行方式
```bash
lua5.4 01-lock-free-queue.lua
```

## 核心概念
- **原子操作**：用表作为共享状态模拟 CAS（比较并交换）操作
- **ABA 问题**：检测值从 A→B→A 的变化，导致 CAS 错误地判定成功
- **内存回收**：延迟释放，避免并发环境中的 use-after-free
- **协作式调度**：协程交替执行，模拟并发的生产者和消费者
- **生产者-消费者模式**：多个生产者入队，消费者安全地出队
- **哨兵节点**：用虚拟的头尾节点简化边界条件
