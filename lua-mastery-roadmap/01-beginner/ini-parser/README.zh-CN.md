# INI 解析器

**阶段**: 1（初级）
**Lua 版本**: 5.1, 5.3, 5.4, LuaJIT

## 概述

一个实用的 INI 文件解析器，用于演示字符串操作与表的构建。本项目培养模式匹配、数据提取和嵌套表组装等基本功——这些是每一位处理配置文件或文本的 Lua 开发者都要掌握的核心技巧。

## 学习内容

- 使用 `gmatch` 和 `gsub` 进行字符串模式匹配
- 从解析出的数据构建嵌套表
- 处理空白字符、注释和节标题
- 从原始文本输入返回结构化数据

## 前置知识

- 第 01 章：基础（字符串拼接、变量）
- 第 02 章：控制流（if/elseif、循环）
- 第 03 章：函数（返回值、局部作用域）

## 运行方法

```bash
lua 01-ini-parser.lua
```

脚本内嵌了一段示例 INI 文本，解析后会打印出配置结果。若要解析自己的输入，可修改脚本底部的 `ini_content` 字符串。

## 核心概念

- `string.gmatch` — 遍历字符串中的模式匹配
- `string.gsub` — 执行全局替换
- Lua 模式 vs 正则表达式 — `%w+`、`%s*`、`[^%[]+` 语法
- 表的构建 — 从扁平输入构建层次结构

## 改进建议

1. 为格式错误的节添加错误处理
2. 支持带引号的值和转义序列
3. 实现 `__tostring` 元方法以便美化输出
4. 为边界情况（空行、重复键）添加单元测试
