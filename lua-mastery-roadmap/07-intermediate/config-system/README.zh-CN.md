# 配置系统

**阶段**: 7 — 中级 | **难度**: 中级

## 描述

读取和写入 INI 风格的配置文件，支持分区、键值对、默认值以及环境变量覆盖。讲解实用的文件 I/O 与数据校验。

## 前置知识

- Lua 5.1+ 或 LuaJIT
- 基本的文件 I/O 知识

## 运行方法

```bash
lua 01-config-system.lua
```

## 核心概念

- INI 文件格式的解析与写入
- 环境变量集成
- 基于 schema 的校验与默认值处理

## 文件

- `01-config-system.lua` — 带校验与覆盖机制的配置读取器/写入器
