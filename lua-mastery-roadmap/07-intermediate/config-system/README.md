# Config System

**Stage**: 7 — Intermediate | **Difficulty**: Intermediate

## Description

Read and write INI-style config files with sections, key-value pairs, default values, and environment variable overrides. Teaches practical file I/O and data validation.

## Prerequisites

- Lua 5.1+ or LuaJIT
- Basic file I/O knowledge

## How to Run

```bash
lua 01-config-system.lua
```

## Key Concepts

- INI file format parsing and writing
- Environment variable integration
- Schema-based validation with defaults

## Files

- `01-config-system.lua` — Config reader/writer with validation and overrides
