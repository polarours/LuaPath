# 第 29 阶段：断路器模式

## 标题
断路器模式 — 通过优雅降级实现容错

## 描述
断路器模式通过监控操作、在失败次数超过阈值时断开电路来阻止级联故障。电路断开时，调用立即被拒绝并返回降级结果。超时后，电路进入半开状态，用于测试服务是否已恢复。

该模式对于微服务和分布式系统至关重要——在这些系统中，远程调用可能失败、超时或变慢。

## 前置知识
- Lua 表和元表
- 闭包和作为值的函数
- 使用 `pcall`/`xpcall` 进行基本的错误处理
- 理解状态机

## 运行方式
```bash
lua5.4 01-circuit-breaker.lua
```

## 核心概念
- **三种状态**：关闭（正常）、打开（故障中）、半开（测试恢复）
- **失败计数**：跟踪连续失败次数以触发断路器
- **超时**：尝试恢复前的等待时长
- **降级行为**：电路打开时返回默认值或缓存值
- **状态转换**：关闭 → 打开（达到失败阈值）、打开 → 半开（超时后）、半开 → 关闭（成功）/ 打开（失败）
