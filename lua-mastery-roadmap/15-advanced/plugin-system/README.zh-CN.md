# 插件系统

**阶段**: 15 — 高级

## 描述
设计一个具备插件发现、生命周期钩子和配置支持的插件加载器。了解 Lua 动态 require 系统如何支撑可扩展架构，以及如何管理插件从加载到关闭的全过程状态。

## 前置知识
- 阶段 01–14 已完成
- 理解元表与模块模式
- 熟悉文件 I/O 和 require

## 运行方法
```bash
lua 01-plugin-system.lua
```

## 核心概念
- 动态插件发现与加载
- 生命周期钩子（init、start、stop）
- 配置注入
- 通过元表实现插件沙箱
- 热重载能力
