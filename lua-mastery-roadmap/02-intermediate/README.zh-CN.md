# 中级阶段

**阶段级别**: 6-10
**Lua 版本**: 5.1, 5.3, 5.4, LuaJIT

## 概述

本阶段通过项目深化对 Lua 核心特性的理解，包括元表、模块、协程和错误处理。

## 项目

| 项目 | 描述 | 技能 |
|------|------|------|
| [实体模型](entity-model/) | 基于组件的实体系统 | 元表、组合 |
| [任务调度器](task-scheduler/) | 基于协程的任务管理器 | 协程、yield |
| [JSON 解析器](json-parser/) | 解析和生成 JSON 数据 | 递归、表格 |
| [配置系统](config-system/) | 配置文件处理器 | 模块、持久化 |
| [模板引擎](template-engine/) | 简单的文本模板 | 字符串操作 |

## 前置知识

- 完成初级阶段项目
- 理解 Lua 表和函数

## 运行方法

```bash
cd <project-name>/
lua <project-name>.lua
```
