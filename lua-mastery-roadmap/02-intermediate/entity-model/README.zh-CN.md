# 基于原型的实体模型

**阶段**: 2（中级）
**Lua 版本**: 5.1, 5.3, 5.4, LuaJIT

## 概述

一个受游戏引擎架构启发的基于原型的实体系统。本项目讲授元表分派、原型继承链和只读覆盖层——这些是在 Lua 中构建灵活、可组合的对象系统时的核心模式。

## 学习内容

- 基于元表的分派，使用 `__index` 和 `__newindex`
- 原型继承（没有类，只有委托）
- 用于保护实体状态的只读覆盖层
- 用于校验和日志记录的代理模式

## 前置知识

- 第 04 章：表（创建、嵌套、迭代）
- 第 05 章：元表（元方法、分派链）

## 运行方法

```bash
lua 02-entity-model.lua
```

脚本会创建示例实体、应用原型，并演示只读行为。

## 核心概念

- `setmetatable` — 为一个表关联元表
- `__index` — 控制缺失键的读取行为
- `__newindex` — 拦截写入以强制不可变性
- `rawget` / `rawset` — 在需要时绕过元表
- 代理模式 — 委托给底层表的轻量包装
