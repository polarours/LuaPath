# Intermediate Stage

**Stage Level**: 6-10
**Lua Versions**: 5.1, 5.3, 5.4, LuaJIT

## Overview

This stage deepens your understanding of Lua's core features through projects that use metatables, modules, coroutines, and error handling.

## Projects

| Project | Description | Skills |
|---------|-------------|--------|
| [Entity Model](entity-model/) | Component-based entity system | metatables, composition |
| [Task Scheduler](task-scheduler/) | Coroutine-based task manager | coroutines, yield |
| [JSON Parser](json-parser/) | Parse and generate JSON data | recursion, tables |
| [Config System](config-system/) | Configuration file handler | modules, persistence |
| [Template Engine](template-engine/) | Simple text templating | string manipulation |

## Prerequisites

- Completion of Beginner stage projects
- Understanding of Lua tables and functions

## How to Run

```bash
cd <project-name>/
lua <project-name>.lua
```
