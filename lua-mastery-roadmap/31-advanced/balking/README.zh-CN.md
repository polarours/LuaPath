# 第 31 阶段：Balking 模式

## 标题
Balking 模式 — 前置条件不满足时跳过执行

## 描述
Balking 模式在对象不处于正确状态时阻止操作执行。与会等待的 Guard 模式不同，Balking 直接返回而不执行任何动作。这适用于只应在特定条件下运行、且没有必要等待的操作。

常见用途包括：一次性初始化、幂等保存，以及必须由就绪检查守护的写操作。

## 前置知识
- Lua 函数和闭包
- 用元表实现对象行为
- 理解状态管理
- 基本并发概念（心智模型）

## 运行方式
```bash
lua5.4 01-balking.lua
```

## 核心概念
- **Balking 守卫**：短路执行的前置条件检查
- **依赖状态的执行**：只在对象处于有效状态时才运行
- **立即返回**：不等待也不重试——直接跳过
- **幂等操作**：可以安全地多次调用而不产生副作用
- **使用场景**：一次性初始化、受守护的写入、资源清理
