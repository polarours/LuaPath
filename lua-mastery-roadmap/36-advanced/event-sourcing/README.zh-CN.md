# 第 36 阶段：事件溯源

## 标题
事件溯源 — 包含命令与投影的不可变事件日志

## 描述
事件溯源把所有变更保存为一系列不可变事件，而不是覆盖当前状态。当前状态由重放事件推导得出。这提供了完整的审计链路，支持时序查询，并支持同一份数据的多个读优化视图（投影）。

本实现覆盖事件溯源的核心模式：仅追加的事件存储、校验并发出事件的命令处理器，以及从事件流构建读模型的投影。

## 前置知识
- Lua 表和元表
- 闭包和作为值的函数
- 基本序列化概念
- 理解状态机
- 熟悉事件驱动架构

## 运行方式
```bash
lua5.4 01-event-sourcing.lua
```

## 核心概念
- **事件存储**：仅追加的日志，记录所有改变状态的事件
- **命令**：改变状态的意图；由处理器校验后才发出事件
- **事件**：已发生事实的不可变记录，带时间戳和元数据
- **聚合**：在命令处理期间强制执行不变式的领域对象
- **投影**：通过重放事件构建的读优化视图
- **重放**：从头重放所有事件以重建当前状态
- **时序查询**：重放事件到指定时间戳，查询任意时刻的状态
- **事件版本化**：支持跨事件版本的模式演进
