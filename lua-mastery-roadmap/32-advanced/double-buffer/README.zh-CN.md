# 第 32 阶段：双缓冲模式

## 标题
双缓冲模式 — 通过交换实现平滑的数据切换

## 描述
双缓冲模式用两个缓冲区把生产者与消费者解耦。一个缓冲区正在被写入时，另一个正被读取。写缓冲区就绪后，两者交换角色。这消除了图形中的闪烁，并保证并发系统中数据的一致性。

在 Lua 中，我们用表引用高效地实现交换，无需复制数据。

## 前置知识
- Lua 表和引用
- 用元表实现受控访问
- 理解生产者-消费者模式
- 基本同步概念（心智模型）

## 运行方式
```bash
lua5.4 01-double-buffer.lua
```

## 核心概念
- **两个缓冲区**：读缓冲区和写缓冲区
- **交换操作**：原子地交换缓冲区的角色
- **生产者写入**后缓冲区
- **消费者读取**前缓冲区
- **一致的快照**：读取永远不会看到部分写入
- **使用场景**：显示渲染、实时数据、游戏状态、日志
