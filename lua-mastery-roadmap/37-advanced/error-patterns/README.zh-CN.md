# 第 37 阶段：错误模式

**级别**: 高级  
**描述**: 在 Lua 中实现类型安全的错误处理模式，包括 Result 类型、Expected 模式和结构化错误码。

## 前置知识

- 第 07 章（错误处理）
- 第 15 章（高级元编程）

## 学习目标

- 实现 Result 类型，实现类型安全的错误处理
- 创建 Expected 模式，提供"值或错误"语义
- 设计带消息的结构化错误码
- 把单子操作应用到错误链上

## 项目

1. `01-result-type.lua` - 不使用异常的类型安全错误处理
2. `02-error-codes.lua` - 基于枚举的错误报告，带消息
3. `03-expected-pattern.lua` - 带单子操作的"值或错误"

## 核心概念

- Result 类型：`Ok(value)` 与 `Err(error)`
- 不使用异常的错误传播
- 用于串联的单子 bind 操作
- 结构化错误码
