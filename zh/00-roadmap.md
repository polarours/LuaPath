# 00 — 学习路线图

## 学习阶段

### 阶段 A：语言核心素养（1–2 周）
- 对应章节：`01` 到 `04`
- 目标：写出语义正确、无动态语言常见陷阱的 Lua
- 阶段项目：文本规则引擎

### 阶段 B：元机制与架构（1–2 周）
- 对应章节：`05` 到 `07`
- 目标：构建可复用抽象与可靠错误边界
- 阶段项目：可插件化配置/运行时框架

### 阶段 C：协作并发与运行时接口（1 周）
- 对应章节：`08` 到 `09`
- 目标：掌握协程调度与标准库工程化用法
- 阶段项目：带任务调度的事件循环

### 阶段 D：虚拟机原理与原生集成（2–3 周）
- 对应章节：`10` 到 `11`
- 目标：能解释 VM 行为，并安全地把 Lua 嵌入宿主
- 阶段项目：C 宿主嵌入 Lua，绑定日志与指标 API

### 阶段 E：性能与生产落地（1–2 周）
- 对应章节：`12` 到 `14`
- 目标：可测量优化、可维护建模、可发布部署
- 阶段项目：ECS 风格模拟沙盒 + 性能报告

- E：优化热点路径并给出前后对比数据

## 常见误解

1. “Lua 天生慢”
   - 误区。多数问题来自分配模式与 table 形态抖动。
2. “table 只是字典”
   - table 是数组/哈希混合结构，性能特征强相关。
3. “metatable 就是面向对象语法糖”
   - 本质是分派钩子，OOP 只是其中一种用法。
4. “coroutine 等于线程”
   - 协程是协作式，不是抢占式并行。
5. “C API 只是 push/pop”
   - 它是严格栈协议 + 生命周期管理问题。

## 何时迁移到 LuaJIT

适合迁移：

- 热点循环占比高，且控制流可被 trace 优化
- 需要 FFI 低开销调用原生接口
- 部署平台允许 LuaJIT

暂不建议迁移：

- 依赖 5.3/5.4 独有语义
- 路径高度多态、trace 难稳定
- 尚未建立基线性能数据

## 何时选择嵌入 Lua

适合嵌入：

- 需要宿主可扩展行为且不希望重编译
- 需要受控脚本沙箱
- 需要快速迭代规则、玩法或策略逻辑

不适合：

- 需求变化率低，静态宿主实现更简单可靠。
