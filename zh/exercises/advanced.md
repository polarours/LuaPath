# 高级练习

## 概念巩固

1. 分析闭包密集代码字节码，解释上值状态变化。
2. 在突发分配负载下调优 GC 参数并记录结果。
3. 重构高多态 table 访问路径，降低元方法 miss。

## 小项目

实现宿主嵌入 Lua 运行时：

- C 宿主创建状态并建立沙箱环境
- 注册原生 API（`log`、`clock`、`metrics`）
- 在配额限制下执行不可信脚本并收集错误

## 调试任务

1. 复现 C API 栈不平衡并按协议修复。
2. 诊断并修复错误 userdata 转换导致的崩溃。
3. 追踪并修复 GC + 分配引发的延迟尖峰。

## 开放式设计问题

1. 脚本与宿主的信任边界应如何强制执行？
2. 多年演进中脚本 API 版本治理如何落地？
3. 如何让 LuaJIT 与标准 Lua 在测试上保持可比行为？
