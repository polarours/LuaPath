# 初级练习

## 概念巩固

1. 不依赖外部库实现 `split(s, sep)`。
2. 用 table 实现 `count_words(text)`。
3. 实现 `clamp` 与 `lerp`，并补全边界测试。

## 小项目

实现命令行“任务清单”工具：

- 新增/列出/删除任务
- 用文本或简易序列化持久化
- 保持模块边界：parser、store、cli

## 调试任务

1. 修复隐式全局覆盖问题。
2. 修复列表渲染中的 off-by-one。
3. 修复 table 空洞与 `#t` 使用错误。

## 开放式设计问题

1. Lua table 如何表达“可空字段”且不引入歧义？
2. 何种模块 API 风格更利于测试？为什么？
3. 小型脚本系统里错误边界应该放在哪？
