│  │  │  1  │  2  │  3  │  4  │  5  │  6  │  7  │  8  │   │  │
│  │  ├─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┤   │  │
│  │  │"a"  │"b"  │"c"  │ nil │ nil │ nil │ nil │ nil │   │  │
│  │  └─────┴─────┴─────┴─────┴─────┴─────┴─────┴─────┘   │  │
│  │         ↑                                      │       │  │
│  │         └────────── size = 3 ──────────────────┘       │  │
│  └───────────────────────────────────────────────────────┘  │
│  ┌───────────────────────────────────────────────────────┐  │
│  │                   Hash Part                            │  │
│  │  ┌─────────────┐    ┌─────────────┐                   │  │
│  │  │  "name"     │    │  "config"   │                   │  │
│  │  │  → "Lua"    │    │  → {table}  │                   │  │
│  │  └─────────────┘    └─────────────┘                   │  │

## Call Stack and Upvalues

```
┌─────────────────────────────────────────────────────────────┐
│                    Call Stack Layout                         │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  ┌────────────────────────────────────────────────────┐     │
│  │  Frame: outer()                                     │     │
│  │  ┌──────────────────────────────────────────────┐   │     │
│  │  │  Locals:                                      │   │     │
│  │  │    R0: x = 10                                 │   │     │
│  │  │    R1: y = 20                                 │   │     │
│  │  │    R2: closure → inner                        │   │     │
│  │  └──────────────────────────────────────────────┘   │     │
│  │         │                                            │     │
│  │         │ (upvalue reference)                        │     │
│  │         ↓                                            │     │
│  │  ┌────────────────────────────────────────────┐      │     │
│  │  │  Upvalue: → R0 (x)                         │      │     │
│  │  └────────────────────────────────────────────┘      │     │
│  └────────────────────────────────────────────────────┘     │
│                                                              │
│  ┌────────────────────────────────────────────────────┐     │
│  │  Frame: inner()  ← Currently executing             │     │
│  │  ┌──────────────────────────────────────────────┐   │     │
│  │  │  Upvalues:                                    │   │     │
│  │  │    U0: → outer's R0 (x) = 10                 │   │     │
│  │  │  Locals:                                      │   │     │
│  │  │    R0: z = 30                                 │   │     │
│  │  └──────────────────────────────────────────────┘   │     │
│  └────────────────────────────────────────────────────┘     │
│                                                              │
└─────────────────────────────────────────────────────────────┘

When outer() returns:
  ┌─────────────────────────────────────────────────────┐
  │  Upvalue is "closed" - value moved to heap          │
  │  inner() can still access x even though outer()     │
  │  frame is gone                                       │
  └─────────────────────────────────────────────────────┘
```

## Garbage Collection Cycle

### Incremental GC (Lua 5.1–5.4)

```
┌─────────────────────────────────────────────────────────────┐
│                   GC State Machine                           │
│                                                              │
│    ┌─────────┐                                               │
│    │  IDLE   │ ← collectgarbage("collect")                  │
│    └────┬────┘                                               │
│         │                                                    │
│         ▼                                                    │
│    ┌─────────┐   mark step                                   │
│    │ MARKING │ ──────────────┐                              │
│    └────┬────┘               │                              │
│         │                    │ (more to mark)                │
│         │ (all marked)       │                              │
│         ▼                    │                              │
│    ┌─────────┐ ◀─────────────┘                              │
│    │ ATOMIC  │   (stop world pause)                         │
│    └────┬────┘                                               │
│         │                                                    │
│         ▼                                                    │
│    ┌─────────┐   sweep step                                  │
│    │ SWEEPING│ ──────────────┐                              │
│    └────┬────┘               │                              │
│         │                    │ (more to sweep)               │
│         │ (all swept)        │                              │
│         ▼                    │                              │
│    ┌─────────┐ ◀─────────────┘                              │
│    │  IDLE   │   (cycle complete)                           │
│    └─────────┘                                               │
└─────────────────────────────────────────────────────────────┘

GC Parameters:
  pause       - Wait multiplier (default 200 = 2x last collection)
  stepmul     - Speed relative to allocation (default 200%)
```

│  │  │ Gen 0   │  │ Gen 1   │  │         │              │    │
│  │  └─────────┘  └─────────┘  └─────────┘              │    │
│  │      │              │                                 │    │
│  │      │ (survive)    │ (survive)                       │    │

## C API Stack Model

```
┌─────────────────────────────────────────────────────────────┐
│                    Lua Stack (C API)                         │
│                                                              │
│  Stack indices (1-based, from bottom):                       │
│  ┌────┬────┬────┬────┬────┬────┬────┬────┐                 │
│  │ -4 │ -3 │ -2 │ -1 │    │  1 │  2 │  3 │                 │
│  ├────┼────┼────┼────┼────┼────┼────┼────┤                 │
│  │arg2│arg1│ func│this│    │ ret│ ret│ ret│                 │
│  │    │    │     │    │    │  1 │  2 │  3 │                 │
│  └────┴────┴────┴────┴────┴────┴────┴────┘                 │
│     ↑              ↑         ↑                              │
│     │              │         │                              │
│  Negative       Top of    Positive                          │
│  (from top)     stack     (from bottom)                     │
│                                                              │
│  Common operations:                                          │
│    lua_push*(L, value)     - Push to top                    │
│    lua_pop(L, n)           - Remove n from top              │
│    lua_to*(L, idx)         - Convert at index               │
│    lua_gettop(L)           - Get stack size                 │
│    lua_settop(L, idx)      - Set stack size                 │
└─────────────────────────────────────────────────────────────┘

Function call pattern:
  1. Push function
  2. Push arguments
  3. lua_call(L, nargs, nresults)
  4. Pop/results are on stack
```

## Performance Hierarchy

```
┌─────────────────────────────────────────────────────────────┐
│              Operation Cost (Fastest → Slowest)              │
└─────────────────────────────────────────────────────────────┘

  ┌──────────────────────────────────────────────────────┐
  │  FASTEST: Register access (local variables)          │
  │  ───────────────────────────────────────────────────  │
  │  local x = 1                                          │
  │  x = x + 1                                            │
  └──────────────────────────────────────────────────────┘
                          │
                          ▼
  ┌──────────────────────────────────────────────────────┐
  │  Upvalue access (closure captures)                   │
  │  ───────────────────────────────────────────────────  │
  │  local function outer()                               │
  │    local x                                            │
  │    return function() return x end                     │
  │  end                                                  │
  └──────────────────────────────────────────────────────┘
                          │
                          ▼
  ┌──────────────────────────────────────────────────────┐
  │  Table array access (integer keys)                   │
  │  ───────────────────────────────────────────────────  │
  │  t[1], t[2], t[i]                                     │
  └──────────────────────────────────────────────────────┘
                          │
                          ▼
  ┌──────────────────────────────────────────────────────┐
  │  Table hash access (string keys)                     │
  │  ───────────────────────────────────────────────────  │
  │  t["key"], t.key                                      │
  └──────────────────────────────────────────────────────┘
                          │
                          ▼
  ┌──────────────────────────────────────────────────────┐
  │  Global access (_ENV lookup)                         │
  │  ───────────────────────────────────────────────────  │
  │  global_var, math.sin                                 │
  └──────────────────────────────────────────────────────┘
                          │
                          ▼
  ┌──────────────────────────────────────────────────────┐
  │  Metamethod invocation                               │
  │  ───────────────────────────────────────────────────  │
  │  __index, __newindex, __add, etc.                    │
  └──────────────────────────────────────────────────────┘
                          │
                          ▼
  ┌──────────────────────────────────────────────────────┐
  │  SLOWEST: C API calls, allocation                    │
  │  ───────────────────────────────────────────────────  │
  │  io.open, table.create, new table in loop            │
  └──────────────────────────────────────────────────────┘


  Optimization strategy:
  1. Move hot path data to locals
  2. Cache globals before loops
  3. Use array part when possible
  4. Minimize allocations in loops
  5. Avoid metamethods in hot paths
```

## Error Propagation

```
┌─────────────────────────────────────────────────────────────┐
│                 Error Propagation Flow                       │
└─────────────────────────────────────────────────────────────┘

  Code:
    function A()
      B()
    end
    
    function B()
      C()
    end
    
    function C()
      error("something failed")
    end

  Execution:
    ┌─────┐
    │  A  │
    │ call│
    └──┬──┘
       │
       ▼
    ┌─────┐
    │  B  │
    │ call│
    └──┬──┘
       │
       ▼
    ┌─────┐
    │  C  │
    │error│
    └──┬──┘
       │
       │ Error propagates up
       │
       ▼
    ┌─────┐     ┌─────────────────────────────┐
    │  B  │────→│ pcall(B) caught it?         │
    └──┬──┘     └─────────────────────────────┘
       │                    │
       │                   NO
       │                    │
       ▼                    ▼
    ┌─────┐          ┌─────────────┐
    │  A  │          │   DEAD      │
    └──┬──┘          │ (unhandled) │
       │             └─────────────┘
       │
       ▼
    ┌─────────────┐
    │   MAIN      │
    │ (program    │
    │  exits)     │
    └─────────────┘

  Handling patterns:
    pcall(fn)              - Protected call
    xpcall(fn, handler)    - With traceback
    assert(fn())           - Error or return
    if not ok then ... end - Manual check
```
